1Create the machine — pick your cloud

Cheapest first. Every path ends the same: a 4 vCPU / 16 GB box with a 2 TB disk, Docker preinstalled, and an IP to paste below.

Hetzner~€120/mo · cheapest

Get an API token at console.hetzner.cloud (project → Security → API tokens), then:

export HCLOUD_TOKEN=…
git clone https://github.com/ivcained/fiddy && cd fiddy && bash scripts/hetzner-deploy.sh
OVHcloud~$190/mo

Create API credentials at api.ovh.com/createToken (GET+POST on /cloud/*), then:

export OVH_APPLICATION_KEY=… OVH_APPLICATION_SECRET=… OVH_CONSUMER_KEY=… OVH_PUBLIC_CLOUD_PROJECT=…
git clone https://github.com/ivcained/fiddy && cd fiddy && bash scripts/ovh-deploy.sh

Open console.aws.amazon.com → the CloudShell icon (>_ top bar) — pre-authenticated. One line:

2Paste your node's IP

The script prints it. Paste it here — the rest of the commands build themselves.

git clone https://github.com/ivcained/fiddy && cd fiddy
bin/fiddy provision --ssh ubuntu@…
bin/fiddy node up

3Watch it sync

The node downloads ~470 GB of snapshot chunks before its API answers — overnight on the default HDD is normal. This polls your node directly; nothing goes through us. Some browsers block the poll from an HTTPS page — the reliable check is bin/fiddy node status from your terminal.
